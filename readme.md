### Hack to the AI Top 初賽  

#### 📌 目標與方法  
在股票市場中，投資人面對眾多選擇，因此我們希望透過 **語言模型 (LLM) + 連續數據判斷**，提供快速且方便的買點預測。  

目前的實作方法：  
1. **動態微調** —— 採用兩個 LLM 作為工作流節點：  
   - **節點 1**：負責生成相關資料  
   - **節點 2**：對節點 1 的輸出進行判讀  

#### 🛠 進度  
✅ **genAI 線上搜尋工具**  

#### ❗ 遇到的問題  
1. **輸出無限迴圈**：  
   - 目前 Gemini 仍根據相同的輸入資料 (`data array`) 產生一致的輸出。  
   - **節點 2** 檢測 **節點 1** 的結果後發現需要重新評估，但由於 **節點 1** 的輸入股票不變，導致輸出的預測點始終相同，形成無限迴圈。  

2. **GCP 費用問題**：  
   - 由於使用付費帳號，導致 GCP 可能會收取 **$58 美元** 的費用，但目前尚未找到解決方案來避免額外開支。
